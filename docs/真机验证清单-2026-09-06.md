## D Android pdfium 三件套（jniLibs 三 ABI）

### D1 按真机 ABI 验 APK 打包（取一验一）
**背景**：仓库 jniLibs 三份源文件——`arm64-v8a/libpdfium.so` 6,402,896 字节（≈6.1MB）、`armeabi-v7a/libpdfium.so` 4,216,652 字节、`x86_64/libpdfium.so` 6,572,216 字节。gradle 自动按 ABI 打包进 APK `lib/<abi>/`。
**验证步骤**（P2 记下的 ABI，以 arm64-v8a 为例）
1. 电脑执行：`adb shell pm path dev.hengya.hengya` → 得到 `package:/data/app/…/base.apk`。
2. 拉回本地：`adb pull <上一步的 base.apk 路径>`。
3. 检查内容（PowerShell）：`tar -tf base.apk | findstr pdfium`（APK 即 zip；或用解压工具）。
4. 核对 `lib/arm64-v8a/libpdfium.so` 的存在与大小。
**预期结果**
- 三 ABI 的 libpdfium.so 都列在 APK 内：`lib/arm64-v8a/`、`lib/armeabi-v7a/`、`lib/x86_64/` 各一份。
- 与真机 ABI 对应的文件大小 ≈6,402,896 字节（解压后精确一致；压缩包内字节数可能略异，以解压后为准）。
- 替代快检（免拉包）：`adb shell dumpsys package dev.hengya.hengya | findstr nativeLibrary` 后 `adb shell ls -l <nativeLibraryDir>`，应看到 libpdfium.so ≥4MB。
