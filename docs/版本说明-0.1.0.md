# 恒牙 0.1.0 版本说明（首个公开发布版本）

> 发布日期：2026-09-09 · versionName `0.1.0` · versionCode **19**
>
> 本仓库自此版本起公开发布。历史上曾有 1.x 内测版本（仅私有小范围分发），公开发布起版本号重新从 0.1.0 计起；Android versionCode 保持严格递增（本版 19），已装内测版（versionCode ≤18）的用户可经应用内更新链无感升级。

## 一、本项目是什么

恒牙是 local-first 的口腔医学间隔复习系统：

- 启动图标：F3 随环倾斜版（微金牙齿 + 独立环带，见 `design/appicon/f3-selected/`）

- **FSRS-4.5 间隔调度** + 待审核池人工终审 + 科目隔离 + 回炉重造闭环
- 端上语料库：教材 / PPT / 真题三源建库，FTS5 词面 + 向量余弦融合检索 + 可选 reranker 精排
- 端上 AI 拆卡流水线：收件箱关键词 → 学习罗盘推进 → 检索取证据 → LLM 拆卡 → 待审池
- 一人一机一库：默认完全离线，AI 能力（拆卡 / 嵌入 / 重排）由用户自备 key 可选开启
- 应用内更新：任意 HTTP 直链分发源（自建 nginx 或 GitHub Release 均可）

## 二、核心功能一览

| 功能 | 入口 |
|---|---|
| 科目管理 / 卡片题库 / 待审核 / 统计 | 四 Tab 主界面 |
| 复习会话（FSRS 调度） | 科目页 → 开始复习 |
| 学习罗盘（章节推进） | 学习进度页 |
| 端上建库（上传课件 → 建库 → 检索） | 设置 → 知识库 |
| 成品语料包一键导入 | 设置 → 数据管理 → 导入语料包 |
| AI 服务配置（LLM / 嵌入 / 重排，key 加密本存） | 设置 → AI 服务 |
| 应用内更新（versionCode 比较） | 设置 → 应用内更新 |
| 一键导出（自动剥离全部密钥） | 设置 → 数据管理 |

## 三、构建与测试

```bash
cd app
flutter pub get
flutter build apk --release        # 默认 BACKEND=local
flutter test                       # 依赖私有语料/金样的用例自动 SKIP
```

详见根 `README.md`。Windows 宿主跑测试自动使用 `test/sqlite3.dll` 与 `test/fixtures/pdfium/`。

## 四、与内测版的差异（仓库层面）

公开仓库做了如下清洗，**App 功能与内测 1.8.2+18 完全一致**：

- 不含任何课程语料与金样 fixtures（版权原因）；对应测试用例自动跳过
- 不含内测期过程文档（修复记录 / 手动测试记录等）
- 不含已退役的服务器端架构（server/ / deploy/）与 Python 参考流水线（automation/）
- 测试中的真实第三方端点替换为占位地址
