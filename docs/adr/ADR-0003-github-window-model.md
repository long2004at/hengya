# ADR-0003 · GitHub 窗口期模型（运行时零依赖）

日期：2026-09-03 ｜ 状态：已定稿

## 决策

GitHub 私有仓库仅用于 **M0–M1 开发窗口期**（用户临时开 VPN 期间）的代码托管与云端快照。窗口期后：

- 运行时链路（自动化↔服务器、App↔服务器）**零 GitHub 依赖**
- 本地 git 仓库始终保留，commit 照常进行（完整历史）
- 备份改走：服务器 SQLite 每日快照（保留 30 天）+ 每周压缩包 SSH scp 回电脑

## 背景

大陆网络下 GitHub 访问不稳定；用户明确"项目构建完成传入 GitHub 后关闭 VPN"。
关键结论：**任何运行时环节经 GitHub 都是不可接受的单点**——卡片生成、评分同步、内容存档均设计为不经 GitHub。

## 恢复开发

未来加功能/修 bug：用户临时开 VPN push/pull，或助手打包改动走本地 git 合并。
