# ADR-0002 · 技术栈：Dart 全栈

日期：2026-09-03 ｜ 状态：已定稿

## 决策

App（Flutter）与服务端（shelf + sqlite3）均用 Dart，两端共享 `shared/` 数据模型包。

## 理由

1. **单一语言**：卡片 schema、FSRS 参数、状态机只需定义一次，两端永不漂移
2. **运行时轻量**：编译为原生可执行文件，容器内存预算 ~150Mi（服务器 1.6Gi 总量，见计划书 §七）
3. **个人维护成本最低**：单人项目，跨语言维护（如 Go 后端 + Flutter 前端）的模型同步成本不可接受

## 取舍

- 放弃 Go/Node 后端的生态成熟度 → 个人单用户场景用不到
- Dart 生态里 sqlite3/shelf 属小众 → 但均为稳定核心库，锁版本可控
