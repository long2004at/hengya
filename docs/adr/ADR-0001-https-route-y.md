# ADR-0001 · 访问方案：HTTPS 公网直连（路线 Y）

日期：2026-09-03 ｜ 状态：已定稿

## 决策

服务器 `https://<SERVER_IP>:8443` 作为**唯一公网入口**：自签 CA 证书（10 年，SAN=IP）+ App 证书固定（pinning）+ 256-bit Bearer token + API 速率限制。手机与电脑自动化均免 VPN、免隧道直连。

## 背景与备选

| 备选 | 弃用理由 |
|---|---|
| Tailscale（路线 T） | 手机零操作诉求无法满足；电脑 Tailscale 与用户 VPN 冲突；大陆 DERP 连通不确定 |
| 域名 + Let's Encrypt（路线 X） | 用户域名即将过期，续费/备案生命周期风险 |
| SSH 隧道 | 每次会话需建/拆隧道，手机端完全不可用 |

## 已知边界（接受）

1. 部分校园网/企业网可能封 8443 高端口 → 报错明确；备选改端口或按需 Tailscale 兜底（v1 不做）
2. 自签证书无公共信任链 → 仅自打包 App（pinning）与 curl（--cacert）可访问，浏览器告警属正常
3. 公网扫描噪音 → token + 限速 + 证书固定纵深防御；fail2ban 兜底 SSH 侧

## 安全红线

真实 IP / SSH 端口 / token / 证书私钥**一律不进仓库**，经 `.env` 或部署时注入。仓库文档以 `<SERVER_IP>` 等占位符表示。
