# RRF 互惠排名融合 · 对照双跑与定型结论（2026-09-06）

## 一、结论（先说结果）

**RRF 不切默认，linear（0.4/0.6 线性加权）保持现状默认。** 真库 6,954 块双跑
三道线：RRF 在 A 线 -7~-11 pct、B 线 -13 pct，全面显著劣化且无「免调权重」
收益可言；C 线 RRF 域内「可过线但语义不可分」（单路结构分 0.50 与真查询
单路答案块同分）。开关保留（`--fusion rrf` / env `FUSION_MODE`），供后续
语料形态变化时复评。

## 二、实现要点（search_corpus.py / validate_retrieval.py）

- **公式**：`score(d) = Σ_i 1/(k + rank_i(d))`，词面/向量两路各按本路
  分数排名（1 起，并列按 chunk_id 升序打破，跨平台确定）；未进某路排名表
  的候选该路贡献 0。k 默认 60。
- **归一化**：原始 RRF 分除以 `2/(k+1)`（两路皆第一的理论上限）→ [0,1]，
  语义=双路名次一致度：双路皆第一=1.0、**单路独占≈0.5**（×PPT 优先乘子
  1.05 后 ppt 块为 0.525）。向量路不可用时退化为词面单路排名（排序与词面
  分排序一致，仅分数域变化）。
- **开关**（优先级：CLI/调用方参数 > env > 内置默认 linear）：
  - CLI：`search_corpus.py --fusion linear|rrf`、`--rrf-k N`；
    `validate_retrieval.py --fusion linear|rrf`、`--rrf-k N`。
  - env：`FUSION_MODE`、`RRF_K`。
  - **env_get 空值语义**：未设置或 `.env` 置空值（`FUSION_MODE=`）均回退
    内置默认 linear——融合模式无「禁用」第三态，空值不构成显式选择；未知
    值在 notes 提示后回退（防 .env 手误静默切换）。已实测三态：rrf(k=60)、
    rrf(k=20)、bogus→linear。
- **兼容**：`--weights` 在 rrf 下不参与融合（仍校验、仍回显）；JSON 顶层
  新增 `fusion` 字段（rrf 时另有 `rrf_k`）；run.py 子进程调用零改动兼容
  （run.py --self-test 79/79 绿）。
- **分数域警示**：rrf 的 score 与 linear 不可通约。下游低分线（run.py
  `LOW_SCORE_FLOOR_DEFAULT=0.30`）与 linear 分数域绑定；validate 在 rrf +
  默认 0.30 floor 时自动注入 notes 提醒按模式重校。

## 三、双跑数据（真库 content/corpus/corpus.db，6,954 chunks）

查询配置 = 上游定论：k=3、weights 0.40/0.60、带 instruct 前缀（默认
QUERY_INSTRUCT）、嵌入 Qwen/Qwen3-VL-Embedding-8B（MRL 1024）。

| 线 | linear 0.40/0.60（默认） | rrf k=60 | rrf k=10（敏感性） | 验收线 |
|---|---|---|---|---|
| A 真实考点 top-3 | **74%（20/27）** | 63%（17/27） | 67%（18/27） | ≥80% |
| A 真实考点 top-1 | **67%（18/27）** | 52%（14/27） | — | — |
| B 同义改写 top-3 | **75%（6/8）** | 62%（5/8） | 62%（5/8） | ≥70% |
| C 生造词不误报 | **4/4 @0.32**（max 0.306） | 4/4 @0.53（max 0.500） | 4/4 @0.53（max 0.500） | 全低于低分线 |

- linear 组复现上游基线逐字一致（A 74%/B 75%/C 4@0.32 max 0.306）——本次
  改动对默认路径零回归。
- C 线 floor 按域分别校准（沿用上游「按配比与库规模校准」先例）：linear
  0.32；rrf 参考线 0.53（实测生造词 top-1 恰 0.500=单路结构分理论值）。
- k 敏感性（10 vs 60）：A 67% vs 63%，B 持平 62%，C 持平——劣化源于域
  结构而非 k 取值，结论对 k 鲁棒。
- 嵌入 API 消耗：每组 39 次查询嵌入（免费档）；linear 47s、rrf 27s（含
  FTS 词面路 + 全库 int8 向量扫描，RRF 无 API 差异，差异来自 IO 缓存）。

## 四、逐查询差异分析（翻转 4 条全量归因）

35 条 real+syn 查询中：同为 OK3 22 条、同为失分 9 条（判定层结构性失分，
与融合无关，佐证上游结论）、**判定翻转 4 条（linear 过 → rrf 挂）**：

1. **「西晋朝史书中有关口腔颌面外科的记载是什么」**：答案 PPT 历史页
   （词面 0.92-1.00、向量 0.36-0.45——历史页在 7,000 块中向量名次靠后，
   RRF 向量路贡献趋零）被「绪论封面/病史记录/创口分类」教材块（向量名次
   靠前）挤出 top-3。
2. **「西晋朝史书已有关唇裂修复术的记载」**：查询词「唇裂修复术」把向量
   路带向「唇裂手术治疗学」块（词面仅 0.08-0.22、向量 0.53-0.55），
   RRF 下三席全被治疗学块占据；linear 靠词面绝对分（l1.00 vs l0.16 的
   6 倍差距）守住「形成和发展」历史答案页。
3. **「龋病的临床特征体现在哪三个方面」**：linear 的 #2/#3「龋病临床
   表现及分类」姊妹块（词面满分）被 RRF 换成「牙髓病临床表现」语义近邻
   块（向量 0.60-0.61），判定词（色/形/质）不再满足 → 挂。
4. **「牙齿慢慢烂掉是什么病」（syn 口语化）**：口语查询词面本就弱
   （「牙齿」「病」大量命中），RRF 抹掉词面绝对分差距，根管治疗/盖髓术
   等语义近邻块上位，挤出 linear 靠词面保位的答案相关块。

**统一机制**：本语料答案块高频呈「词面强/向量弱」（PPT 口语标题、历史
记载、术语精确匹配 vs 语义距离远），linear 的 0.4 词面权重 + 绝对分差
是这些块的守门员；RRF 把两路绝对分全部抹成纯名次，向量路的语义近邻干扰
块系统性上位。hit_path 分布佐证：35 条查询 top-3 共 105 席中，单路块
linear 占 8 席（lexical 4 + vector 4）→ rrf 只剩 3 席——**RRF 结构性
偏向双路一致块、挤掉单路强证据块**。

**C 线分数域对照**（生造词 4 条）：linear 0.254-0.306（余弦绝对值有
语义距离信息，0.32 floor 是真实语义边界）；rrf 4 条 top-1 全部恒 0.500
（单路独占结构分，与「真查询但只有一路能召回」的答案块同分不可分），
top-2/3 仅差 1.6%（RRF 名次分数的密集性）。**RRF 域 C 线技术上可过线
（floor≥0.53），但「误报抑制」与「单路召回」不可区分**——若切 rrf 为
默认，run.py 的 0.30 命中判定需连带重校且会把全部单路真命中滤掉。

## 五、定型依据汇总

1. A/B 双线全面显著劣化（-7~-13 pct），RRF 无任何占优维度；「免去调权重」
   的收益无从谈起（linear 的 0.40/0.60 两轮 A/B 已定稿，无调参痛点）。
2. 4 条翻转逐条归因在案，劣化机制明确且结构性（词面强/向量弱的答案块 +
   语义近邻干扰），非实现 bug：合成库 --dry-run（卡片→chunk 精确映射
   判定）下 rrf 同样 96%/100%/4/4 达标，实现正确性独立验证。
3. C 线在 rrf 域语义不可分（单路结构分），切换会连带破坏 run.py floor
   契约（LOW_SCORE_FLOOR_DEFAULT=0.30 与 linear 分数域绑定）。
4. k 敏感性 10→60 无翻盘，劣化对 k 鲁棒。

## 七、下游指引

- 生产/流水线（run.py）继续用默认 linear：`--fusion` 不传即可，行为与
  2026-09-05 定稿完全一致。
- 需要实验 rrf 时：CLI `--fusion rrf [--rrf-k N]` 或 env `FUSION_MODE=rrf`
  `RRF_K=N`；**必须**同时按 rrf 域重校下游低分线（validate 参考 0.53；
  run.py `--floor` 需另行实测校准），且预期 A/B 线劣化约 10 pct。
- 后续语料若转向「多路异构检索源」（>2 路、分数量纲不可比、无绝对分
  语义）场景，RRF 可重新评估——本结论仅对当前「FTS 词面 + 单模型余弦」
  双路同源架构成立。
