# 改造整体复核（2026-10-09）

范围：复习页、雾层、六档评分、统一语料工作台，以及相邻评分持久化、资料删除、导入与恢复链路。以下确定问题已直接修复；不是所有结论都经过运行验证。

## 修复的高风险问题

1. 离线补传原来整队 clear，会删除请求在途时追加的新评分。改为单飞、按快照确认、串行持久化；存储未初始化或写入失败不能宣称评分保存成功。SharedPreferences 自身的失败缓存也会重载。
2. 本地评分的批量外壳 ok=true 可能掩盖单条拒绝。客户端现在看对应条目是否受理。记忆状态、日志与数据版本在同一 SQLite 事务内提交；同一卡片、同一作答时间重放不重复调度。
3. 原件上传只捕获 ApiException，磁盘或权限异常会遗留不能关闭的进度弹窗。改为统一 try/finally，准确移除自己的 DialogRoute，不弹走其他页面；读取前校验 200 MB 限制，并防重复导入。
4. 全新语料目录的删除日志原来先于数据库创建落盘，准备阶段中断可能使恢复无从判断。现在数据库及提交标记表先建立，再写日志；准备失败的暂存文件会清理，已落日志的待恢复文件则保留。

## 交互和边界修复

- 贴文字雾层使用实际纸片尺寸判定纸角，不再误用外层 Expanded 的高度。
- 小高度 / 横屏复习布局增加滚动退路，避免固定控制栏挤出卡片。
- 补齐 Tap 取消的预览清理，并避免它覆盖已经开始的横向评分手势。
- 语料列表与详情的并发只读请求排队执行；写入、换库、备份仍保持互斥。
- 全部科目筛选使用 null，不与旧库里可能存在的 @all 科目 ID 冲突。
- 大纲目录中的非 DOCX 文件不再误标为可建库。
- 资料详情明确提示：展示的是已抽取文字，不保证包含原件里的图片、扫描页或解析失败内容。

## 验证与限制

新增故障回归覆盖了并发补传、失败持久化、评分事务回滚及重放、上传异常与超限文件、准备中断恢复、并发资料读取、雾层小纸片与横屏等场景。

按 AGENTS.md，本地只执行静态分析和差异检查，没有运行测试、没有构建 APK。回归测试需要 CI 执行，Android 低内存、大字体、文件选择/分享、雾层连续擦拭和性能仍需真机验收。

默认 local 的本地评分已补上幂等保护；历史 remote 服务端不在本仓库，客户端无法独自保证服务端对重复 HTTP 提交的幂等性。

跳过仍是会话内暂缓，不改变下一次复习时间；退出后按原有到期队列重建。语料删除没有回收站，误删需从备份恢复。批量操作、修改分类、应用内 PDF 图像阅读与 OCR 仍是功能边界，不能把「数据库记录全部展示」等同于「原文件所有信息全部解析」。

存量离线评分 JSON 损坏的旧分支原先静默返回空队列，下一次写入可能覆盖原始内容。本轮已改为保留原始内容并阻止覆盖，修复成功后才能恢复离线写入；自动修复这些存量坏数据的工具仍未实现。
