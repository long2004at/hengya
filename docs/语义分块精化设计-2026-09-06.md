# 恒牙 · 教材 PDF 语义分块精化设计（2026-09-06 定稿）

> 状态：**定稿**（2026-09-06）。本文档是「检索优化最大项：语义分块」节点的设计先行稿，
> 实测证据全部来自本仓库当前语料（12 本教材 PDF 书签树与正文、corpus.db 2616 chunks、
> 2026-09-06 上一节点 A/B 前缀定论报告）。改造对象 **仅** `automation/server-pipeline/extract_pdf.py`
> 的教材（source_type=textbook）分块路径。

---

## 0. 结论先行

教材分块从「书签节(章) + 4000 字贪心段落装箱」精化为「书签单元 + 行内标题层级递归切分」：

1. **修复内容丢失**：无 level-2 子书签的 level-1 章此前被整章丢弃（**oms《口腔颌面外科学-第8版》第一章 绪论 p13-15 即重灾区——正是上一轮 A 线 4 条 oms-intro 失分卡的答案正文缺失根源**：检索只召回 PPT 封面页 p1-2（0.799 高分但正文只有标题和「知识目标」），真正含「两门学科结合/定义/业务内容」的教材绪论根本不在库里）。
2. **块界落在主题切换处**：单元内按行内标题（第X节 → 一、 → （一） → 1.）递归切分，4000 字章块不复存在；单块≈一个知识点。
3. **块标题带标题路径**（`章·节·一、住院病历书写要求`），实质词入题 → FTS 词面路（TITLE_WEIGHT=2.0）与向量路（title+\\n+text 契约）双双受益。
4. **行级页源**：每块 page_start/page_end 精确到行所在页，取代页粒度贪心切分（跨页腰斩消失）。

**硬性不变**：`extract_pptx.py`（PPT 单页天然单元，oms 金样 md5 `b884a9d1…` 必须不变）、
`extract_docx.py`（大纲按标题分块已语义化）、教材 PDF 的**真题/按页路径**（exam 按页、
答案解析原样保留）、toc sidecar 契约（progress_db 输入不变）、chunks.jsonl 字段契约。

## 2. 定稿规则

### 2.1 单元选取（_textbook_units 增强）

- units = **L2 书签**（现状）∪ **无 L2 子女的 L1 章**（新增；此前整章丢弃）。
- 孤儿 L1 经非正文关键词过滤：标题含 `目录 目录尾 索引 前言 参考文献 版权页 书名 封面 封页
  附表 对照表` 之一 → 仍丢弃（endo 目录/索引等现状行为不变；mucosa 附录「主要名词和定义」
  为真实定义性内容，随规则纳入）。
- 单元边界：沿用「其后下一条 level≤2 书签起始页-1」倒扫机制（孤儿 L1 的边界同样被覆盖）。

### 2.2 行级页源

单元文本由 `[(page_no, line)]` 行列表承载（每页逐行 strip、空行丢弃，与 `_page_text` 同口径，
**严禁改写**）。块 page_start/page_end = 块首/末行所在页。

### 2.3 层级递归切分（核心）

对单元行列表递归：

```
块长 ≤ 1600        → 整块输出（标题路径 = 当前路径）
块长 > 1600        → 在「下一层级」标题行处切分，逐组递归
  L1: ^第[一二三四五六七八九十百零]+节
  L2: ^[一二三四五六七八九十]+、
  L3: ^[（(][一二三四五六七八九十]+[）)]
  L4: ^\d{1,2}[、.．](?!\d) 且 len≤45 且不含 [，,；;：]
四级用尽仍 > 1600  → _split_paragraphs 段落贪心至 1600 兜底（-sN 后缀）
```

- 标题行本身入块文本（不丢内容）；组内小节块后续并入（见 2.5）。
- 「第X节」行常拆成两行（`第一节` + 下一行节名）：标题行恰为裸「第X节」（len≤6）且下一行
  ≤40 字无句读 → **仅标题路径**吸收下一行（文本不动）。
- 依据：2.3 表实测——知识点的自然边界密度（568/281/820）远高于 soft 阈值触发频率，
  块界因此几乎全部落在真实主题切换处。
- **二轮迭代（同日）**：段落兜底上限由 2600 收敛到 1600——首版 2600 实测暴露无标题流
  的向量稀释（oms 绪论 2600 字三段 0.66 上下，不敌 96 字 PPT 标题页 0.80；降到 1600 后
  库内 chunk 6641→6954，无标题流块与有标题块同颗粒度）。

### 2.4 块标题 = 单元题 + '·' + 标题路径（首部重复折叠）

如 `第二章 口腔颌面外科基础知识与基本操作·第一节 口腔颌面外科病史记录·一、住院病历书写要求`。
书签节名与行内节名同文时路径首部重复段折叠（避免「…第一节 X·第一节 X·…」——oms 节单元、
endo 绪论节均如此，二轮迭代增补）。依据：上一轮 A 线失分剖析——「住院病历包括哪些内容」
的答案块（p16-20）已进入 top-3 但判定层因正文 4000 字 blob 无子标题而失判；子标题入题后
「病历」入题、块内正是 11 项清单。标题同时进 FTS（TITLE_WEIGHT=2.0）与向量（title+\n+text）。

### 2.5 短块并入前块

块长 < SHORT_SECTION_CHARS(150)（沿用现值）→ 并入前块：page_end 扩展、文本追加、title 取前块。
跨单元的尾短块同样并入（与现行「短节并入前块」语义一致）。

### 2.6 chunk_id

沿用 `chunk_id_of(subject, deck, page_start, page_end)` + `-sN` 撞号兜底（页码更精确后撞号大幅减少）。

### 2.7 不变面

- toc sidecar（chapters/sections 书签导出）逐字节同构；progress_db --init 不受影响。
- 真题/课件 PDF 按页路径（`_blocks_by_page`、EXAM_PAGE_SPLIT_CHARS=2500）零改动。
- `refresh_corpus.py --incoming` 的 PDF 走 source_type="ppt" → 按页路径，零改动。
- extract_pptx.py / extract_docx.py 零改动（PPT 金样 md5 硬门）。

## 6. 结论与建议

- 分块目标全部达成：单块中位 ~650 字（知识点颗粒度）、块界全部落在真实标题行、
  行级页源、内容零丢失（守恒断言 + 新旧全量对账 +20135 字=孤儿章回收）、PPT/真题/
  docx 金样 md5 逐字节不变。
- **A 线工具判定 74% < 80% → 按纪律不 commit，交用户裁断**。裁断输入：
  1. 人工抽核口径 A=81.5%（22/27）≥80%——两条差额均为「答案块 top-1 + 4 字残差闸拒判」；
  2. 若重开 2026-09-05 的 maxblock≥5 闸（缩小为「查询唯一实质词完整出现在候选标题」
     等窄规则），A=81.5% 工具口径达标，但需重审当时「7 条真 miss 无一误放」的对账；
  3. intro 5 条的检索改善需查询侧/判定侧配合（超出本节点分块边界）。
