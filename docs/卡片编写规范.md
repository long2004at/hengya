# 口腔复习卡片 · 编写规范 v1

> 目标：每张卡都经得起考试检验。宁可 80 张扎实的卡，不要 300 张注水的卡。

---

## 一、五条硬性原则

### 1. 最小信息原则
一张卡只考一个点。判断标准：如果答案里有"和、以及、并简述"，这张卡大概率该拆。

- ❌ 坏卡："简述龋病的病因、分类、临床表现和治疗原则"
- ✅ 拆成：四联因素卡 × 1、分类卡 × 2（按进展速度 / 按累及深度）、临床表现卡 × 3（浅/中/深龋）、治疗原则卡 × 1

### 2. 主动回忆导向
题干必须逼你"提取"，而不是"再认"。

- ❌ "四联因素包括细菌、食物、宿主、时间，对吗？"（判断题式，可以蒙）
- ✅ "龋病病因的四联因素学说是哪四个因素？请逐一说明其作用。"

### 3. 来源可追溯
每张卡标注来源：教材章节 + 小节（如"龋病 · 病因 · 四联因素学说"）。
**术语、定义以指定教材原文为准**，不做教材外的自由发挥；教材未覆盖的内容需单独标记"拓展"并征得你确认后才入库。

### 4. 题干自包含
不依赖上下文。禁止"上述""该病变"这类指代——卡片会被算法打乱顺序出现。

### 5. 答案有锚点
答案部分给出评分锚点（关键词），自评时对照锚点判定"会/不会"，避免"感觉会了"的自我欺骗。

## 二、卡片类型体系（六种）

| 类型 | 适用内容 | 示例（龋病章） |
|---|---|---|
| 定义卡 | 名词解释 | "猛性龋（rampant caries）的定义是什么？好发于哪些人群？" |
| 列举卡 | 因素/分类/表现（强制拆分，单卡 ≤ 4 个要点） | "按累及深度，龋病分为哪三类？" |
| 对比卡 | 易混概念 | "急性龋 vs 慢性龋：病程、质地、颜色、好发人群各有何区别？" |
| 填空卡 | 需要精确记忆的数值/术语 | "深龋时龋坏已达牙本质____层，距牙髓____。" |
| 病例卡 | 诊断与鉴别（Boss 战素材） | "患者冷热刺激痛，刺激去除后疼痛立即消失，探诊龋洞达牙本质深层，无自发痛。诊断？需与什么鉴别？" |
| 图像卡 | 临床/病理照片识别 | （配 PPT 插图）"图示龋坏位于哪个牙面？属于哪一类？" |

## 三、单卡数据格式（JSON）

```json
{
  "id": "caries-001",
  "type": "列举卡",
  "chapter": "龋病",
  "section": "病因 · 四联因素学说",
  "source": "教材第X版 · 龋病章 · 病因节",
  "question": "龋病病因的四联因素学说是哪四个因素？",
  "answer": "细菌、食物、宿主、时间",
  "anchors": ["细菌", "食物", "宿主", "时间"],
  "difficulty": 2,
  "tags": ["病因", "高频考点"]
}
```

- `anchors`：自评判定的关键词，缺一不可判"会"
- `difficulty`：1–5，用于闯关模式的关卡编排
- `source`：入库必填项，无来源的卡不入库

## 四、生产与审核流程（你握有终审权）

1. **我出初稿**：从 PPT + 你的手打重点拆卡，每张卡带来源标注
2. **你逐张审**：标记 保留 / 修改 / 删除（可在表格里批量操作）
3. **修改意见回灌**：你改过的卡我会归纳成新的编写规则，追加到本规范，后续批次自动遵守
4. **入库**：只有通过审核的卡进入复习队列

> 建议节奏：先拆"龋病"一章作为试点批次，跑通"拆卡 → 审核 → 背诵"全流程后再扩展到后续章节。

## 五、考核形态适配（2026-09-02 定稿）

用户课程考核形态：**期中全选择题；期末少量选择题 + 病历分析简答题 + 知识类简答题**。

由此确定卡型配比原则：

1. **Basic 主动回忆简答卡为主力（约 60%）**——期末主体是简答，平时必须用"看问题→口头/笔头完整作答→对照锚点自评"的方式训练，严禁用再认式卡片应付。
2. **Cloze 填空卡为辅（约 40%）**——服务期中选择题和期末少量选择，用于史实、数值、条目等事实性内容。
3. **提问方向双向校验**：年份↔事件类考点（如 1952 年），优先"给事件问年份"（贴合选择题形态），简答级考点用"给主题问内容"。
4. **病历分析题对应"病例卡"**——后续章节遇到完整病例（如 PPT 中的舌癌住院病历示例），做成"给病历→说诊断依据/缺项分析"的综合卡，即闯关模式的 Boss 战素材。
5. **关键词工作流正式确立**：用户提供课堂关键词（索引）→ 助手按关键词检索 PPT 原文（事实源，检索式三级递进：关键词原句 → "科目名+章节名" → 同义表述）→ 命中则还原完整 QA + 锚点 + 出处 → 用户终审；三级仍未命中 → 生成**占位卡**（back=`【PPT 未覆盖】请结合课堂笔记/教材补全原文后审核`，tags 加 `待补原文`，status 仍 pending 照常进待审池；完整字段定义见 §七 v1.2 规则三），并在报告中输出**未命中清单**（列关键词与已尝试的检索式），由用户按课堂笔记/教材补全原文后审核，绝不臆造。

## 六、来源三级体系（2026-09-02 增补，用户明确要求）

用户要求：**卡片与课程 PPT 强关联，答案绝大部分必须来自 PPT**；同时利用**执业医师考纲与个人知识库真题**校准。

### 来源优先级（不可颠倒）

| 级别 | 来源 | 作用 | 约束 |
|---|---|---|---|
| ① 主源 | 课程 PPT（IMA 知识库） | **答案主体**：题干和答案必须从 PPT 原文还原 | 答案不脱离 PPT 表述；术语以 PPT 为准 |
| ② 校准源 | 执业医师考纲 + 真题（"次方的知识库"：2016–2025 执业/助理真题、技能考试 PDF、第 8 版教材） | a) 判定考点权重（真题高频 → 标`真题高频`）；b) 校准提问方向（照真题题型出问法）；c) 发现 PPT 未覆盖的考纲要求点 | 真题/考纲内容**不得替换** PPT 答案，只影响权重和问法 |
| ③ 拓展源 | 教材（第 8 版等） | 仅当 PPT 未覆盖而考纲要求时补充 | 必须标【考纲拓展】，经用户确认后入库 |

### 三层语料口径与教材罗盘三职能（2026-09-05 增补）

**三层语料**：PPT=答案主源；教材=罗盘三职能；真题=已学范围内可直接出卡。

**教材罗盘三职能**（教材不作答案源）：

1. **框定已学范围**——出卡与真题检索只在已学章节内进行；
2. **进度锚**——当前学到哪一章由学习进度库承载（见下「学习进度库」小节）；
3. **对齐执业医师考纲**——考纲版本口径：《医师资格考试大纲（2024年版）》（国卫医考委发〔2023〕3号）+ 医学人文部分 2026 年修订（国卫医考委发〔2026〕1号）。

### 每批卡片的固定动作

1. 拆卡完成后，对每章内容在真题库做一次交叉检索；
2. 检索结果只改两样东西：**优先级标签**和**提问方向**，不改 PPT 答案；
3. 在审核稿中注明交叉验证结论（如"本章历史内容真题零命中 → 维持了解级"）。

### 关键词≠全部内容 的应对

用户课堂关键词只作索引。每批卡片除覆盖关键词外，还须对照 PPT 该章知识目标（掌握/熟悉/了解）检查**关键词遗漏的"掌握级"内容**，以"建议补入"形式提交，用户可删。

### 真题两通道（2026-09-05 增补）

- **通道 A · 每日主跑跟随关键词**：主跑对每条关键词在真题库检索，真题卡每关键词 **≤2 张**，宁缺毋滥（0 张正常）；
- **通道 B · 周度扫题（周日）**：每周日 21:00（**时刻可调**）独立扫题，每周真题卡 **≤30 张（此数字醒目标注可调）**，科目间均衡分配；模板见 `automation/prompts/周度扫题-周日.md`；
- **真题卡字段（两通道统一）**：`sourceTier`=exam、`examYear`=真题年份、`front`/`back`（以真题解析为据、术语以 PPT/教材校准）、`anchor`=年份+题号、`tags` 含「真题」、`status` 全部 pending；
- **幂等 id**：`exam-{科目}-{年份}-{题号}`（服务端 import 重复自动 skip）；
- **排除口径**：exam 源下 deck 名含「大纲」的考纲 deck 不作为出卡对象——考纲是范围罗盘不是题源（库内现有 4 个考纲 deck：执业大纲 23 chunks / 助理大纲 19 / 人文两份各 12）。

### 学习进度库（2026-09-05 新增）

学习进度库（默认 `content/progress/progress.json`）承载教材罗盘职能②进度锚：**10 科章节指针**，`source`∈{seed, manual, auto}，**仅单调前进（不可回退）**。

**schema**：anatomy 11 章 / endo 8 / imaging 18 / implant 21 / mucosa 17 / oms 23 / patho 7 / peri 24 / prevent 19 / prostho 13，另有 derm 0 章占位。

**progress_db CLI 契约**（`automation/server-pipeline/progress_db.py`；参数以脚本 `--help` 实际输出为准；退出码 0/2，倒退即 exit 2）：

- 契约速记：`--init / --force / --show / --json / --learned <subject> / --set <subject> <no> / --source seed|manual|auto / --advance <subject> --from-title "标题" / --chapter <no> / --progress <path> / --toc-dir <dir> / --self-test`；
- `--init`：从 toc sidecar 建/刷新进度库（保留进度与历史）；
- `--force`：配合 `--init`——无视已有进度全量重建（清零清史）；
- `--show`：全科目进度一览（含已学章名）；`--json`：配合 `--show` 输出完整 JSON；
- `--learned <subject>`：单科目详情（已学章名+下一章+历史）；
- `--set <subject> <no>`：手动校正章序（默认 source=manual；单调，倒退 exit 2）；
- `--source seed|manual|auto`：history 记录来源标签（默认 manual；种子建议 seed）；
- `--advance <subject>`：自动推进，配 `--from-title "标题"`（检索命中的教材标题，教材块 title=「章名·节名」）或 `--chapter <no>`（source=auto）；
- `--progress <path>`：progress.json 路径（默认 `content/progress/progress.json`）；`--toc-dir <dir>`：toc sidecar 目录（默认 `content/corpus/toc`）；
- `--self-test`：合成 sidecar 断言自测。

**代设纪律**：进度值须用户拍板后代设。已定种子（2026-09-05 用户校正）：endo 4/8、oms 4/23、anatomy 11/11（口解已学完）、patho 7/7（组病已学完）、prevent 19/19（预防已学完）、derm 0（占位）；牙周（peri）与黏膜（mucosa）未学、本学期无相关课程，保持 0；其余科目（imaging/implant/prostho）保持 0 待用户后续校正。

## 七、修订记录（用户审核意见回灌）

### v1.1（2026-09-02，第一批审核反馈）

**规则：禁止"总览复述型"卡片，时间轴类内容必须拆成单事件卡。**

- 背景：第一批卡 04"按时间顺序复述发展史标志性事件（汉→1959）"实为 7 个知识点打包，用户审核时判定"知识点包含太多、太广"。
- 执行标准：一个朝代/年份/人物 = 一张卡（如"孙思邈做了什么"一张，"汉朝记载了什么"一张）；**单卡答案包含的事件数 ≤ 1**。
- 例外：整体脉络可作为某张卡的**背面附注**呈现（帮助定位上下文），但不得作为问题本身。
- 双向校验不受影响：同一事实的 Basic 卡（主体→事件）与 Cloze 卡（事件→主体）可同时存在，用户反馈队列过重时可按标签暂停其一。

### v1.2（2026-09-04，主跑模板修订同步）

**规则一：拆分单位 = "一个考点的完整作答"。** 考试里作为一个整体设问、需一口气答完的内容 = 一张卡；两个独立设问点（如病因 + 治疗原则）= 必须两张卡。

- 两个禁止极端：① 禁止一卡多问（如"简述A、B和C"）；② 禁止碎拆完整考点的内部条目（如"四联因素之一是什么？"）——整体设问的答案条目不得单独成卡。
- 判定线：back 要点 ≤ 4；超过，或答案出现"和、以及、并简述"触发词 → 说明该拆（§一 最小信息原则的执行标准）。
- 与 v1.1 的关系：时间轴单事件卡同理——一个事件 = 一个考点，不属过度拆分，"单卡答案包含的事件数 ≤ 1"标准不变。
- ✅ 好例："深龋的治疗原则是什么？"（一个设问一口气答完）；❌ 坏例："简述龋病的病因、分类、临床表现和治疗原则"（一卡多问）。

**规则二：问法必须对齐考核形态。** front 模拟真实考核设问（期中全选择题；期末少量选择 + 病历分析简答 + 知识类简答）。

- 简答级考点用试卷设问动词（简述/试述/列举/比较/分析）；事实数值类优先"给事件问年份/数值"的选择题化问法（§五 第 3 条双向校验）。
- 禁止清一色机械问法（全批都是"什么是X？"）；同一考点不要机械正反各出一张，只出最贴考法的方向。
- 病例分析类内容必须做成病例卡（type=caseChain）：题干给病例信息，问诊断/依据/鉴别。
- ✅ 好例："急性龋与慢性龋在病程、质地、颜色上有何区别？"（期末比较类简答的真实考法）；❌ 坏例："什么是急性龋？"（机械名词化问法）。

**规则三：PPT 未命中 → 生成占位卡（废除【待确认】机制）。** 关键词检索三级递进（原句 → "科目名+章节名" → 同义表述）仍未命中 → 生成占位卡：front=该考点的正式设问、back=`【PPT 未覆盖】请结合课堂笔记/教材补全原文后审核`、type=basic、sourceTier=ppt、source=`PPT 未命中·占位待补`、tags 加 `待补原文`；status 仍 pending 照常进待审池，对应关键词照常 consume，由用户按课堂笔记/教材补全原文后审核，绝不臆造。

- 报告同步输出未命中清单：`PPT 未命中：N 条（列关键词与已尝试的检索式）`。
- 真题/考纲只能校准权重和问法，不得作答案来源（呼应 §六来源三级体系）；IMA 连接器故障降级为本地缓存 PPT 文本检索生成，未命中同样出占位卡，不阻断整批。
