# 恒牙（hengya）——把课堂自动变成复习卡片的开源学习系统

> 面向初审评定的项目说明书 · 创作思路与技术方案 · Markdown

## 一句话介绍

恒牙是一个本地优先（local-first）的通用间隔复习学习系统：任何有课件、有教材的课程，上课时记下几个关键词，当晚 AI 自动把课件、教材、真题「拆」成一张张带原文出处的复习卡片，次日进入科学的间隔复习节奏——**做卡自动化，复习可溯源**。项目首个落地场景是口腔医学专业课程（专业内容为示例，机制完全通用）。

---

## 一、创作思路：从三个真实的痛出发

凡是「上课有 PPT、考试有教材、复习靠自觉」的课程，学习者都会被三件事反复消耗：

1. **做卡太慢。** 间隔复习（Anki 一类）被反复证明有效，但它的前提是「有好卡片」。一节 90 分钟的课，手动把课件提炼成规范卡片要 1–2 小时——做卡的时间远超复习的时间，多数人因此半途而废。
2. **卡片不可信。** AI 直接生成的答案可能出错。如果卡片不能追溯到「出自哪份课件第几页」，用户不敢背。
3. **资料是割裂的。** 课堂课件、教材、历年真题是三类各司其职的资料：课件是老师强调的重点，教材是权威表述，真题标明考点权重。手工整理时它们常常互相打架（同一知识点课件与教材说法不一致该信谁？），需要一套明确的规则。

恒牙的答案是：**把「拆卡」这个高门槛动作交给 AI + 本地检索流水线，把「审核」这个判断动作留给人，把「复习节奏」交给间隔复习算法。** 用户的日常被压缩成：上课记 3 个关键词 → 晚上自动出卡 → 审核批准 → 按天复习。

## 二、技术方案：三个角色分工

整条流水线里有三个「角色」，用比喻说：**向量模型是图书管理员，LLM 是出题老师，用户是审稿编辑。** 下面按「向量模型 → 检索机制 → 打分系统 → LLM」的顺序展开。

### 1. 向量模型：给每段话生成「意思指纹」

向量模型（文本嵌入模型，1024 维向量，本地 int8 量化存储）在项目里有**两个使用场景**：

**场景一：建库。** 课件、教材、真题导入后，App 先把它们切成大小合适的段落（一页 PPT、教材的一小节），再把每一段交给向量模型生成一个高维向量——可以理解为**给每段话生成了「意思指纹」：意思相近的段落，指纹就相近**。指纹连同原文一起存入本机语料库（SQLite + 向量索引），并记录内容指纹（md5）：资料更新时只重新处理变动的块，不必全量重算。

**场景二：查重。** 每张新卡入库前，题干也会被向量化，与已有卡片逐一比对「意思指纹」的夹角（余弦相似度）。相似度超过阈值（0.92）就标记为「疑似重复」，并在审核界面把两张卡并排展示给用户裁决——从机制上杜绝「同一知识点反复出卡」。

一句话：**向量模型不参与「写答案」，它负责让机器在几千个段落里找得到、找得准，并认出「这两张卡其实在讲同一件事」。**

### 2. 检索机制：三级检索式 + 双路并行 + 双源证据池

**第一步：把一句课堂笔记变成一组检索式（三级递进）。** 用户记的关键词往往很短（如「光合作用的影响因素」），直接搜可能漏。流水线按三级递进生成检索式：① 关键词原句 → ② 科目名 + 当前学到章节名 → ③ 让 LLM 生成最多 6 条同义表述（如「光合作用效率的决定条件」）。上一级命中就不再消耗下一级——**省额度，也避免过度检索引入噪音**。

**第二步：每个检索式走「双路并行」。** 词面路按字面精确查找（全文索引，专治术语、名词）；向量路按「意思指纹」相似度查找（专治换了一种说法的内容）。两路各取候选，融合排序（见打分系统）。

**第三步：证据池组装。** 拆卡时课件（PPT）与教材**并行检索、合并去重**，组成一个最多 12 条的证据池；每条证据自带来源标签（课件还是教材）与页码。真题走独立通道（只取「真题」类资料），不与正文混池。所有检索都按科目隔离、按资料类型过滤——搜这门课绝不会串到那门课。

### 3. 打分系统：谁排在前面，谁被淘汰

双路候选如何合成一个排名？由四层规则决定：

| 规则 | 通俗解释 |
|---|---|
| **融合配比 40 : 60** | 词面分与向量分按 4:6 加权合计总分——字面对得上很重要，但「意思对」比「字面像」更权重 |
| **低分线 0.30** | 总分低于 0.30 直接视为「没找到」，宁缺毋滥——不让勉强及格的段落混进证据污染 LLM |
| **课件小幅加权 ×1.05** | 两段得分几乎并列时，课件（老师的课堂口径）排在教材前面 |
| **科目 / 类型过滤** | 科目隔离 + 资料类型（课件/教材/真题）过滤，先划范围再排名 |

打分系统的另一半是**「配额约束」**——它决定了「出多少、出多难」：

- 每个关键词最多拆 6 个子考点、每个子考点最多 2 张卡（是上限不是配额，宁缺毋滥）；
- 每个关键词最多附 2 张真题卡；每周真题扫题总量封顶；
- 评分低于低分线的检索命中一律不进证据池。

### 4. LLM：在原文约束下「出题」

检索到的证据交给 LLM（OpenAI 兼容接口，支持主备模型自动切换），按一份严格的《卡片编写规范》生成卡片，核心约束包括：

- **单卡单考点**：答案里出现「和、以及」就该拆成两张；
- **主动回忆导向**：题干必须逼你「提取」，而不是「再认」；
- **来源可追溯**：每张卡必须标注锚点——出自哪份课件第几页（如「第 3 章课件 p12-15」），审核时一眼可查；
- **来源三级体系**：课件是答案主体，真题/考纲只校准考法与权重，教材与课件并列互校（两者冲突时**以教材为准**）。

**「拆卡」的完整流程**（每晚 22:55 自动运行）：

```
课堂关键词「光合作用的影响因素」
   ↓ 三级检索式 → 双路并行 → 打分排名 → 双源证据池
   ↓ LLM 拆卡：先出「子考点计划」，再逐考点生成卡片 JSON
   ↓ 落库：锚点标注原文出处，向量查重，进待审核池
用户审核：批准 / 编辑 / 拒绝（附理由）
```

**「改卡」（回炉）是同一套能力的闭环**：用户点「拒绝/回炉」并写下理由（例如「按教材的说法改」）后，流水线会**把理由文字并入检索式**重新取证，再让 LLM 按理由重写这张卡——理由说「以教材为准」，就喂教材证据；理由说「太粗了」，就按子考点拆细。改卡完成后回到待审核池重新过人工闸门。

### 5. 工程兜底

- **人工闸门**：所有 AI 产物先进「待审核池」，人批了才算数；
- **成本与稳定性**：主备 LLM 自动切换、当日 token 熔断、失败关键词自动留待补跑、嵌入批量限流退避。

## 三、使用说明书：六步上手

### 第 1 步 · 配置 AI 密钥（apikey）

在设置页填入自己的模型密钥（OpenAI 兼容接口，支持配置主模型 + 备用模型）。

**这一步的意义**：AI 能力完全由你自带——用哪家模型、花多少钱、消耗多少额度，全部由你掌握；密钥保存在系统安全存储中，不进项目文件。主备双模型还能在主力服务故障时自动兜底。

### 第 2 步 · 导入课程资料：课件、教材、考试大纲

把课程的 PPT / 基础教程放入对应科目的资料目录；教材与目标考试的大纲、真题同样支持导入。导入后一键「建库」——App 会把所有资料切块并向量化，生成本机语料库。

**这一步的意义**：这些资料是整张卡片的「证据来源」。课件是答案主体，教材是权威校准，考试大纲与真题负责校准考法——资料越全，拆出的卡片越可信，锚点也才能精确到「第几页」。

### 第 3 步 · 每天下课后，记一次收件箱

打开收件箱界面：① 选择课程 → ② 点选（或手输）今天学到的章节 → ③ 输入课堂上的热乎关键词或知识点，用顿号分隔。

**这一步的意义**：这是你每天唯一的「作业」。关键词哪怕再简洁——只写一个名词也完全生效：三级检索会自动扩展同义表述，LLM 会把大考点拆成小考点。趁热记录还有额外收益：所学章节会同步推进学习罗盘，后续出题与复习都以此为锚。

### 第 4 步 · 触发制卡：自动或手动

默认每晚 22:55 自动运行拆卡流水线；也可以在设置页手动「强制开始制卡」，或自定义运行时间。

**这一步的意义**：把批量计算放在你不用手机的时段，省钱也省心；「强制开始」则满足「现在就想看卡」的场景——比如课前预习或考前突击。

### 第 5 步 · 审核入库：AI 起草，人拍板

新卡片全部进入**待审核区**：逐张查看题干、答案与原文锚点，批准进题库、就地编辑，或拒绝并附上理由（理由会驱动 AI 按你的要求重写，改完回到待审区）。

**这一步的意义**：这是质量的最后一道闸门。AI 只负责起草，判断权在人——尤其医学等严谨内容，每张卡都经你的眼睛确认过，背起来才有底气。

### 第 6 步 · 按到期时间复习

每张卡都带有算法（FSRS）计算的**到期时间**；打开复习页完成当天到期卡片，按真实掌握程度评分（重来 / 困难 / 良好 / 简单），评分直接决定这张卡下一次出现的间隔。

**这一步的意义**：间隔复习的核心是「在快忘的时候复习」——太早浪费时间，太晚已经忘了。坚持每天清空到期卡，记忆曲线就被算法接管，你只管认真完成每一天。

## 四、为什么适配知乎社区

1. **人群精准重合。** 知乎聚集了海量大学生、考研与各类资格证备考者，以及「间隔重复 / 主动回忆 / Anki 值不值得用」这类学习方法论的长期讨论者——恒牙解决的问题正是这些讨论里被反复提及的「做卡成本」环节。
2. **天然的内容素材。** 每张卡片都带「教材页码 + 课件页码」锚点，天然适合做成知乎回答/文章里的**真实案例截图**：从「我上课记的 3 个关键词」到「AI 拆出的 10 张卡」再到「审核前后的对比」，是一条完整、可信、可复现的分享链路。
3. **方法论实践的落地工具。** 知乎上讲「间隔复习」的高赞回答很多，但多数停留在道理层面；恒牙把方法论固化成了「记关键词 → 审核 → 每天复习」的最小动作，是那些回答的「可执行版本」，容易引发「我用它实践了 30 天」式的真实讨论。
4. **开源 + 本地优先，合规干净。** 项目 MIT 开源；课件、教材属于版权敏感内容，恒牙的语料库、数据库、进度全部留在用户手机本地，AI 接口使用用户自带的密钥——不碰云端存储用户资料，符合社区对隐私与版权的预期。

---

## 五、结语

恒牙不是「又一个背题 App」。它把间隔复习里最重的那一环——做卡——拆成了「向量检索找证据 → LLM 约束起草 → 人工审核把关」的三步流水线：向量模型负责让机器在课件与教材里找得到、找得准、认得出重复，打分系统负责让最相关的原文排到最前面，LLM 负责在原文与规范的约束下把考点写成卡片，人负责最后的判断。**学习的主动权在人，重复劳动交给机器。**（口腔医学专业课程是它的第一个落地场景，但机制面向所有「有课件、有教材」的课程通用。）
