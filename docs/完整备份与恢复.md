# 完整备份与恢复

## 使用

入口：**设置 → 恒牙 → 数据管理**。

- **立刻备份**：位于「一键导出并分享」正下方；立即生成完整 ZIP，不受主库自动备份的 48 小时间隔限制。后台生成并校验成功后才显示成功；保留最近 7 份完整包。
- **分享最近完整备份**：把已生成的 ZIP 另存到应用外。应用内副本位于应用数据目录的 `backups/full/`，**卸载应用、清除应用数据或设备损坏都会丢失该副本**，建议另存到电脑或其他存储。
- **导入数据库（迁移）**：选择完整 ZIP，等待校验，核对卡片/复习记录/科目/语料/向量/课件统计后点「确认恢复」。这是整套替换，不是合并；包内不存在的知识库/进度也会恢复为不存在。
- 原「一键导出并分享」仍导出仅主库 `.db`；旧 `.db` 文件仍可导入，但不含向量库、学习进度和原始课件。完整 ZIP 必须用支持完整备份的新版应用恢复，不能交给旧版「导入语料包」入口。

## 范围

| 数据 | 处理 |
|---|---|
| `hengya.db` | 全部主库表，包括卡片、复习记录、科目、收件箱、回炉队列、笔记、调度状态、非敏感设置 |
| `corpus/corpus.db` | 整库一致性快照：语料块、向量 BLOB/维度/缩放、嵌入模型信息、向量镜像或旧虚表及影子表、FTS、建库状态、大纲等均保留，不重新计算向量 |
| `corpus/progress.json` | 学习进度、已学章节、跳过记录和历史 |
| `corpus/toc/` | 已保存的章节目录 |
| `corpus/incoming/` | 应用中实际保存的教材、课件、真题、大纲等源文件 |
| `corpus/chunks.jsonl`、`extract_manifest.json` 及其他持久附属文件 | 保留；已纳入包中的绝对课件路径在恢复到不同目录时重定位 |
| API Key / 系统安全存储 | 不打包；主库中残留的 `*.apiKey` 也从副本清除并压实，源库不受影响 |
| 私有更新地址 `update.source` | 不打包，避免泄漏 URL 中的私有 token |
| 日志、运行标志、缓存、临时文件、历史备份、CLI `.env`/`secrets` | 不打包 |
| 系统权限、通知设置等设备级状态 | 不在此学习数据包内；恢复不会复制系统安全存储或系统权限 |

未实际保存进应用目录的外部源文件不可能凭路径自动备份；若恢复时发现不能重定位的外部课件路径，会提示重新关联。没有知识库的新安装也能备份，但不会虚报存在向量。

## 一致性与安全

- 数据库使用 SQLite online backup，包括尚在 WAL 中的已提交数据；不使用裸拷 `.db` 代替完整快照。
- 完整备份与恢复期间阻止新的本地数据操作和流水线启动；正在建库、拆卡或导入时要求先等任务完成。
- `backup.json` 记录格式版本、时间、文件清单、尺寸和逐文件 SHA-256。创建包后用恢复校验器再验一遍，验证成功才发布文件和轮转旧完整包。
- 恢复先校验包、尺寸、CRC/SHA、数据库结构及学习元数据，然后准备完整暂存件。路径穿越、绝对路径、重复名、链接、未声明文件等会被拒绝，原数据保持不动。
- 完整恢复采用同卷换入和事务记录：异常回滚主库与整个知识库目录；换入时被系统中断，会在下一次启动打开数据库之前回滚未提交恢复，已提交的恢复只清理旧件。
- API Key 需在新设备重新填写。相同设备原有安全存储不被覆盖；模型和端点等非敏感设置随主库恢复。

## 当前边界

完整包使用标准、非加密 ZIP32，可供普通 ZIP 工具查看；包内含私人学习资料，请妥善保管。

安全上限：单数据文件 2 GiB，解压总量 8 GiB，压缩包小于约 4 GiB，数据文件最多 20,000 个，单份 JSON 元数据最多 8 MiB。超过限制会明确失败，**不会静默漏备**。大库处理在后台分块执行，但仍需为数据库快照、压缩包和校验暂存件预留足够磁盘空间。

## 验证

定向用例：

- `app/test/full_backup_test.dart`：完整往返、WAL、向量及模型/FTS/旧虚表保留、密钥剔除、滚动保留、跨目录路径、损坏包拒绝、切换失败回滚和中断恢复。
- `app/test/full_backup_ui_test.dart`：按钮位置、真实 worker 落盘、防连点、重复备份、ZIP 确认/取消/恢复、旧 DB 导入、失败反馈和维护互斥。
- `app/test/data_manager_test.dart`：既有主库导入/导出/自动备份回归。

系统文件选择器、系统分享及大体积真实语料的内存/耗时，仍需在 Android 真机上验收；桌面 widget 测试仅模拟平台文件选择，备份和恢复业务均实际执行。
