# 恒牙 · App 图标概念稿（第一轮）

面向中国口腔执业医师备考 App「恒牙」的启动图标概念探索。品牌叙事：让知识像恒牙一样——长牢了，就永远属于你。

## 硬性要求符合性

| 要求 | 状态 |
|---|---|
| SVG 矢量格式 | ✅ 全部手写 SVG，无滤镜、无位图依赖，可无损缩放 |
| 1:1 · 1024×1024 全出血方形 | ✅ 圆角不画入图内，由启动器自行裁切 |
| 主形置于中央 ~66% 安全区 | ✅ 六稿主形均控制在中心 66% 内 |
| 48px 可辨识（硬门） | ✅ 全部经 resvg 真 48px 光栅验证，主轮廓清晰 |
| 无任何文字/字母/数字 | ✅ |
| 牙齿不作主体 | ✅ 仅 A 稿含「似星又似冠带根」抽象双关，D 稿线顶含蓄暗合山峦/冠形 |
| 分层版 | ✅ 每个 SVG 内含 background/foreground 两组；已导出前景(透明)/背景 PNG |

## 六个概念

| 稿 | 名称 | 意象 | 底色 | 点缀 |
|---|---|---|---|---|
| A | 恒环·星栖 | 横置无限环带（一笔不断开）+ 环上栖星：上如星芒、下收根形 | 品牌渐变 135° | 纯蓝 |
| B | 恒环 | 不断开的圆环/轨道，倾侧悬浮，光扫过环缘的瞬间 | 品牌渐变 垂直 | 香槟金流光 + 星火 |
| C | 恒星 | 恒久发光的四芒星（恒星=永恒之星），深夜恒光 | 午夜蓝 径向 | 极光余晖+疏星 |
| D | 一笔恒线·山恒 | 一笔画完回到起点；线顶为不对称双峰山脊，底线为大地 | 深蓝 垂直 | 纯蓝 |
| E | 白龙 | 内部代号「白龙」抽象化：单笔白色飘带，尾挑腹满首回 | 午夜蓝 | 右下极光 + 金鳞光 |
| F | 极光光弧 | 三道自夜幕升起的流动光弧，与 App 极光氛围同源 | 夜幕+地平辉光 | 纯蓝 |

## 目录结构

```
appicon/
├─ svg/          # 六稿 SVG 矢量源（每组含 background / foreground 分层）
├─ png/
│  ├─ full/      # 完整图标 1024 / 512 / 192 / 96 / 48（48 为真实光栅辨识度验证）
│  ├─ fg/        # 前景层 1024（透明底，仅主图形）
│  └─ bg/        # 背景层 1024（满幅底色）
├─ preview/
│  └─ index.html # 预览页：掩膜网格 + 48px 硬门测试 + 分层合成演示
├─ tools/
│  ├─ render.js  # 渲染脚本
│  └─ package.json
└─ README.md
```

## 渲染

```powershell
cd D:\heng\design\appicon\tools
node render.js
```

改 SVG 后重跑即可重出全部 PNG（6 概念 × 5 尺寸 + 前景/背景层）。
