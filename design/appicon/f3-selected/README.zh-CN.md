本文件夹只收录这一版，不混入牙齿竖直版、F1/F2 或其他草稿。图标和源素材从已选 F3 原文件完整复制，未重新设计，未改变颜色、位置、牙根或留隙。此前所有版本仍在原处保留。

- 牙齿：低饱和的浅香槟金，保留微弱金属光。
- 方向：随环倾斜；环带有牙的右侧下沉，不把牙单独扶正。
- 结构：牙与环没有连接、没有接触。
- 留隙：保持 F3，1024 原图名义间距 7.84px（约 8px）。
- 规格：1024×1024 全出血方形，无文字、无预绘圆角。

**先看 `preview.png`；使用主图请取 `01-icons/icon-1024.png`。**

## 正确使用图层

所有 PNG 图层都是 **1024×1024，同一画布、同一原点**。

- 简单用法：`background-1024.png` 在底，`foreground-1024.png` 在上。
- 独立编辑：依次叠加 `background-1024.png` → `ring-1024.png` → `tooth-1024.png`。
- **不要同时叠加完整前景和单独的环/牙**，否则会重复绘制边缘。
- 不要单独裁紧牙齿或环带的透明边界；否则需要重新对齐位置。
- 不要提前裁圆角，交由启动器处理。

完整 SVG 的 `background` / `foreground` 为命名层；`ring-independent` / `tooth-independent` 为独立对象。牙齿没有额外的扶正旋转，请保留共同变换，不要将之前竖直试验版的旋转参数带入。
